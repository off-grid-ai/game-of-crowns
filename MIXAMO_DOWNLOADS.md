# Mixamo moves for the character view

The lords, ladies and petitioners in the character view are Mixamo-rigged, so
any Mixamo animation plays on them as-is. Download these from mixamo.com
(search the name, pick the first close match):

**Settings for every download:** Format **FBX Binary (.fbx)** · Skin **Without Skin** · Frames per second **30** · Keyframe reduction **none**. Tick **In Place** whenever it's offered.

Save them all into `~/Downloads/Aldmere/mixamo/`, keeping Mixamo's file names. I copy them into the game, and each one appears as a button in the view.
