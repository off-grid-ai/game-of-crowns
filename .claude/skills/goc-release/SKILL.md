# Release

1. **The repo:** `off-grid-ai/game-of-crowns`, private, branch `main`. Push after a change is seen working; small commits, one subsystem each.
2. **Pushes:** clean tree, one at a time, in the background. Never force-push `main`.
3. **Big or risky work** (a migration, a new system) goes on a branch with a PR: what changed, why, before/after screenshots under bold one-line captions.
4. **Show Ali.** Screenshots of every new screen and scene, sent as they land, each with a one-line caption. Name anything not yet seen working.
5. **Keep the docs true.** README for setup and how it fits together; DESIGN.md for decisions and the roadmap; record a reversed decision with its date.
6. **Licences.** Credits stay with each asset (`license.txt`); nothing third-party goes public without Ali's yes.
7. **No public release, no visibility change** without Ali's yes.
