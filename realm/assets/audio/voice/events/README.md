# The realm's calls

One fixed call per big moment, and the names said after some of them (`../names/`), all in one voice: deep, slow
and big, in a hall (Kokoro `bm_daniel`, pitched down). Made with Off Grid AI Desktop (OGAD), its local Kokoro
text-to-speech, shaped by ffmpeg, encoded with oggenc; remake with `zsh realm/tools/record_calls.sh`.
Played by `sound_v2.gd` announce from each moment's one place (`realm/data/sounds.json` `calls`). `war_won` and `war_lost` are recorded but not called: the realm's wars end at the peace table, never won or lost.
