# Supervisor ledger

Where things stand, so any agent can take over. Newest first, short. The full history up to 2026-11-15 is in
`~/wednesday/goc-archive/docs/SUPERVISOR_LEDGER-to-2026-11-15.md`.

## How to take over
- Read `CLAUDE.md`, then `GAME_DESIGN.md`. The working rules are the `goc-*` skills (start with `goc-cpto`).
- One supervisor routes; builder sessions own their files: Bridge (bridge/, terrain, ground, units, traffic),
  Square (towns, town scenes, merged meshes, the bake), Look (woods, villagers, castles, bulk drawing, colours),
  Loop (camera, interface, cards, court, objectives), Army command (selection, orders, battle cards). Each finishes
  code on main with a compile check only; the supervisor tests. A vision partner session holds the design docs.
- Mac tests the game himself. Launch it for him (`./realm.sh open`, one Godot only); never run test games beside
  his. When his game freezes, copy his `godot.log` first, then `kill -SEGV` it for the GDScript backtrace.
