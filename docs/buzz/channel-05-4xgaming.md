**Title:** You can't move a single soldier. How many levers does a ruler need?

I'm building a medieval sim where great houses run themselves. They farm, starve and go to war. As King you can't command anyone. You get grain, gold, taxes, marriages, and which side you back in a war. Every lever costs something, and the houses remember.

Too few levers and you're only watching. Too many and you're running everything. Which game got the balance right for you?

(First build is free for Apple Silicon Macs if you want to see where I landed: https://github.com/off-grid-ai/game-of-crowns/releases)
