# The herald's building calls

What the herald says when the King orders a building (`order_<n>`) and when it stands (`built_<n>`): sept, granary,
walls, market, barracks and aqueduct, three ways each so it never repeats. Same voice as the realm's calls (Kokoro
`bm_daniel`, pitched down, in a hall), made with Off Grid AI Desktop's local Kokoro text-to-speech, shaped by ffmpeg and
encoded with oggenc; remake with `zsh realm/tools/record_calls.sh works`. Played by `sound_v2.gd` herald_work
(`realm/data/sounds.json` `works_calls`).
